# 📊 Unemployment Analysis Using Python

## 📌 Project Overview

This project is developed as part of the Horizon TechX Data Science Internship Program.

The objective of this project is to analyze unemployment trends using Python and data visualization techniques.

---

## 🚀 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib

---

## 📂 Dataset

The dataset contains unemployment statistics across different states and regions.

Key columns:

* States
* Date
* Estimated Unemployment Rate
* Estimated Employed
* Labour Participation Rate

---

## 📊 Project Workflow

1. Import Libraries
2. Load Dataset
3. Data Cleaning
4. Data Exploration
5. Visualization
6. Trend Analysis
7. Insights Generation

---

## 📈 Analysis Performed

* Average unemployment rate analysis
* State-wise unemployment comparison
* Time-series visualization
* COVID-19 unemployment trend analysis

---

## ▶️ How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Upload the dataset file.
3. Run all cells.
